# Output Notes

This folder contains public-safe outputs from the Bike Sales Tableau dashboard project. The files are designed to help recruiters and reviewers understand the project without needing to open Tableau first.

## Included Outputs

- `dataset_profile.csv`: dataset size and basic scope.
- `brand_summary.csv`: bike brand-level summary for dashboard review.
- `state_sales_summary.csv`: state-level sales summary.
- `owner_type_summary.csv`: resale and mileage comparison by owner type.
- `seller_type_summary.csv`: seller type comparison.
- `dashboard_output_summary.md`: plain-language dashboard result summary.
