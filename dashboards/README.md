# Dashboard Notes

The main dashboard was built in Tableau using the Indian bike sales dataset.

## Local Workbook

The local project includes a Tableau packaged workbook named `BikeSaleDashboardCA1.twbx`. It is not uploaded in this public phase because dashboard workbooks can include embedded data and should be checked carefully before publishing.

## Dashboard Purpose

The dashboard is designed for quick business review of bike sales performance across brand, state, owner type, seller type, and pricing measures.
