# Bike Sales Dashboard - Tableau

Dashboarding project focused on bike sales performance, customer segments, and visual business reporting using Tableau.

## Why I Built This

Sales dashboards help stakeholders quickly understand performance without reading raw spreadsheets. This project was built to practise dashboard layout, business summary design, and clear visual communication.

## Business Questions

The dashboard is designed to show sales performance, customer or product patterns, and areas where the business can compare results across categories.

## Tools Used

Tableau, Excel or CSV data, dashboard design, visual analytics, and business reporting.

## What I Implemented

I prepared the sales dataset, built a Tableau dashboard, organised visual views for business review, and documented the dataset and dashboard purpose.

## Repository Guide

The dashboards folder is for the Tableau workbook. The data folder is for dataset notes or sample data. The reports folder is for supporting report material or exports.

## Outputs And Results

The project output is a Tableau dashboard that helps review bike sales performance and communicate findings visually.

## Project Walkthrough

A good way to explore this project is to start with the README, then review the Tableau workbook or screenshots as they are added. The project highlights dashboard design, data visualisation, and business communication skills.
