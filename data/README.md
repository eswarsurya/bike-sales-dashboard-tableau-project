# Data Notes

This project uses an Indian bike sales dataset for Tableau dashboard analysis. The public dataset fields describe vehicle and sales attributes such as state, brand, model, price, mileage, owner type, seller type, resale price, and city tier.

## Public Sharing

The dataset does not contain names, emails, phone numbers, or direct personal identifiers. A smaller public sample is included for GitHub review, while the dashboard evidence is documented through output summaries and visuals.

## Files

- `public_sample_bike_sales_india.csv`: public sample rows for quick review.
