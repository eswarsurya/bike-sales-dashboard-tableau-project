# Report Summary

This project was completed as a Tableau data visualisation assignment focused on Indian bike sales. The report supports the dashboard by explaining the dataset, the visual choices, and the business questions behind the analysis.

## Report Focus

- Dataset understanding and field review.
- Dashboard design choices for business users.
- Sales, resale, and vehicle attribute comparison.
- Clear visual communication for non-technical stakeholders.

## Public Version

The original PDF report is kept local for now. This summary gives recruiters a safe view of the project context while avoiding unnecessary file clutter.
